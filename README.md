# O Gorman Home Improvements

![Live Site](https://img.shields.io/badge/Live_Site-Online-success?style=for-the-badge&logo=github)

The official landing page for **O Gorman Home Improvements**, a professional, fully-insured local service based in Dublin, Ireland. 

**Live Link:** [https://kc-7.github.io/ogHome/](https://kc-7.github.io/ogHome/)

## About The Project

This website serves as a digital storefront for O Gorman Home Improvements, specializing in residential exterior cleaning and home rejuvenation services across Dublin City and County. 

### Key Services Offered:
* **Window Cleaning:** Traditional and modern high-reach water-fed pole systems with purified water.
* **Gutters, Fascias & Soffits:** Complete clearing and exterior washing to protect against damp.
* **Pressure & Soft Washing:** Driveway, path, and patio cleaning using task-specific biocides.
* **Painting & Decorating:** High-quality interior and exterior painting services.

## Features & Highlights

- **Modern & Responsive Design:** Built to look perfect on desktops, tablets, and mobile devices.
- **Service Pricing:** Transparent service cards and detailed pricing tables for all major services.
- **Before & After Gallery:** An interactive, responsive photo gallery showcasing real results.
- **Local SEO Optimized:** Targeted specifically for Dublin locations, featuring JSON-LD structured data and semantic markup.
- **Sticky Mobile CTA:** Immediate "Call Now" and "WhatsApp" contact buttons locked to the bottom of the screen on mobile devices for quick conversions.

## Technologies Used

- HTML5
- CSS3 (Vanilla + Custom Properties)
- [Bootstrap 5](https://getbootstrap.com/) (Grid and Components)
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) for smooth scroll animations

## Setup & Local Development

This project is a static layout requiring no backend or build step. 

1. Clone the repository.
2. Open `index.html` in any modern web browser to view the site locally.
